AI News Hub

AI News Hub is an AI-powered news summarization application built using:

- Google Gemini AI
- Supabase
- Streamlit

## Features

- AI-generated news summaries
- Search news
- Category filtering
- Featured news
- Analytics dashboard
- Responsive interface

## Tech Stack

- Python
- Streamlit
- Supabase
- Google Gemini AI
- Plotly
